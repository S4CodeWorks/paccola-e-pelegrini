## 📌 Overview

A refined digital presence designed for the **Paccola & Pelegrini** law firm. Highlights key legal practice areas, case evaluation pathways, and direct client consultation channels.

---

## ⚡ Highlights

- **Executive Aesthetic**: Typography, refined contrast ratios, and dark/light balance appropriate for legal counsel.
- **Service Domain Cards**: Clear breakdowns for civil, corporate, tax, and labor advisory practices.
- **Direct Engagement**: Optimized mobile-friendly contact actions via WhatsApp and direct call triggers.

---

## 💻 Tech Stack

- **Framework**: React 18
- **Build Tool**: Vite 5
- **Styling**: Tailwind CSS
- **Icons**: Lucide React
- **Deployment**: Vercel
